## 6. Technical Interview Preparation Plan

### 6.1 Azure & Cloud Infrastructure
* **Azure Identity & Security:** Managed Identities vs. Service Principals, Key Vault integration with AKS via CSI Secret Driver.
* **Networking:** VNet peering, Private Endpoints, Network Security Groups (NSGs), Application Gateway / Azure Front Door.
* **Terraform Scenarios:**
  * How do you prevent race conditions and handle state locking in a multi-dev team? *(Azure Blob Storage backend with state leases)*
  * How do you import pre-existing infrastructure into Terraform without downtime?
  * What is your strategy for breaking down monolithic state files into reusable modules?

### 6.2 Kubernetes & Container Operations
* **Pod Lifecycle & Debugging:**
  * What commands do you run when a pod is in `CrashLoopBackOff` or `Pending`? (`kubectl describe pod`, `kubectl logs --previous`, checking node resource pressure).
  * How do you diagnose and fix `OOMKilled` (Exit code 137)?
* **Helm:** Templating values, managing environment-specific configurations (`values-prod.yaml`), rollback procedures (`helm rollback`).
* **Deployments:** Rolling updates, Blue/Green, Canary deployments with ArgoCD / Ingress controllers.

### 6.3 Incident Management & SRE
* **The RCA Framework:** Be prepared to walk through a real incident using the 5 Whys:
  1. *What was the impact?* (e.g., 502 Bad Gateway for 12 minutes)
  2. *What was the immediate fix?* (e.g., rolling back the latest deployment or scaling replicas)
  3. *What was the root cause?* (e.g., unhandled exception or connection pool exhaustion)
  4. *What permanent preventative measures were taken?* (e.g., added readiness probes, rate limiting, and alert thresholds)

## 7. Crucial Questions to Ask in the Screening Call

When the recruiter contacts you, ask these questions to evaluate the quality of the role:

1. **Client & Project Profile:** *"Could you share more details about the client's industry and what the AI projects specifically entail?"*
2. **Work Arrangement:** *"Is this position 100% remote, hybrid, or on-site at Infinigent's office?"*
3. **Working Hours & Timezone:** *"What are the expected working hours? Is there an overlap requirement with US or European timezones?"*
4. **On-Call Policy:** *"Is there an after-hours on-call rotation for production emergencies, and how is off-hours incident response compensated?"*
5. **Contract Type:** *"Is this a direct permanent employment contract with Infinigent, or a fixed-term contract aligned with the client's project?"*
